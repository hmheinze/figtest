Colour Variables — WCAG Scales

50–900 ladders for every Prada Beauty brand hue. Original brand swatches (★) are pinned at their natural step, so brand identity is preserved while the surrounding scale fills in WCAG-accessible tints and shades. Cosmetic lipstick shades sit in their own shade.* primitives group.

Reading the chips. W = contrast against #FFFFFF · B = contrast against #000000. Flags: AAA·W ≥ 7:1 normal text on white, AA·W ≥ 4.5:1, AA·L·W ≥ 3:1 (large text / UI). Same applies for ·B on black.

Use as a Figma frame. Recreate this layout 1:1 in the design file (frame: “Colour Scales — WCAG”). Every hex value here matches the new primitives.tokens.json exactly, so the Figma variables library can be regenerated by importing that file via Tokens Studio for Figma.
